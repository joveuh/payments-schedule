# Security

This project has no formal release versions — the `main` branch is always the
supported one.

## Reporting a vulnerability

Open a [GitHub issue](https://github.com/joveuh/payments-schedule/issues) describing
the problem. This is a personal-use tool with no server-side accounts or stored
credentials, so reports don't need to stay private — but flag the issue title as
"security" so it's easy to spot.
